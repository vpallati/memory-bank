The design in one line: one bank for everything your AI agents need to know about you. Memories flow in continuously from the tools you already use, get distilled into facts with sources, and leave only through scoped, expiring, revocable grants — never as a raw dump. This page is the clickable V1 proof of that loop; live account connectors are the next build step.

Vault rules

The conscience of the bank — enforced on every single call.

No master keys
Every token is scoped, expirable, and revocable. Agents never see the raw vault.
Denial leaks nothing
“Not permitted” and “doesn’t exist” return the identical response, so agents can’t probe for what’s hidden.
Memories can fade
Stale facts decay in ranking; conflicts surface to the owner, who is always the final arbiter.
Patterns, not secrets
Finance memories store the pattern (“card payment made”) — never account numbers or credentials.
02

Permission grants

This is the product. A grant says which agent may read which topics, at what depth, and until when. Sensitive topics always need a human tap; a grant can be killed instantly and the agent’s very next call fails.

Create a grant

In the full flow, the agent asks with a reason and this arrives as an approval ping on your phone: Approve · Deny · Once · Narrower.

Issuing a grant mints a scoped token (shown under the grant). It can never be widened later — a broader scope needs a new approval.

05

How agents connect

Two front doors, one permission engine. REST for everything; MCP so memory shows up as native tools inside agent frameworks. SDKs are thin wrappers over REST — convenience, not a third protocol. The project is being built in the open, intended for release under the MIT license.

REST API — v1 surface

Every call carries a scoped token. The engine checks who, what topic, depth, expiry, and rate on each request.

POST/v1/grants/requestagent asks, with a reason
POST/v1/grants/:id/approveowner approves / narrows
GET/v1/memories/query?q=…scoped retrieval
GET/v1/memories/topicstopics visible to this token
DELETE/v1/grants/:idrevoke — effective instantly
GET/v1/auditowner-only read history
